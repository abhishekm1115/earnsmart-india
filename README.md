# EarnSmart India

एक responsive Hindi website जो beginners को freelancing, content creation, AI tools और online job safety की शुरुआती जानकारी देती है।

## Files
- `index.html` — website content
- `style.css` — responsive design
- `script.js` — mobile menu, current year और learning suggestion form

## Run locally
`index.html` को किसी browser में खोलें। कोई build step या package install करने की जरूरत नहीं है।

## Publish free with GitHub Pages
1. GitHub पर `earnsmart-india` नाम का **Public** repository बनाएँ।
2. इस folder की सभी files repository के root में upload करें।
3. Repository में **Settings → Pages** खोलें।
4. **Deploy from a branch** चुनें, branch `main` और folder `/(root)` चुनकर Save करें।
5. GitHub Pages का प्रकाशित URL Settings → Pages में दिखाई देगा।

## Customize
`index.html` में text और links बदलें; रंग और layout के लिए `style.css` संपादित करें।

## Important
यह शुरुआती educational website है, कोई earning guarantee नहीं देती। किसी platform की fees, availability और monetization rules उसकी official website पर जाँचें।
